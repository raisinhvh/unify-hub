# Roblox

Inspect and run Luau, edit scripts, capture viewport images (saved as PNG or uploaded as image assets), read output logs and selection, and control playtests across multiple Roblox Studio places through the paired DSH Bridge plugin. Uploads models, images, decals, audio, video, and Blender/FBX animations to the group through Open Cloud, inserts models into Studio, and manages uploaded assets (info, metadata, new model versions, version history, rollback, archive/restore, experience permissions, upload quotas).

## Tools

- `roblox_capture_view` — Capture Studio viewport images with camera metadata. No arguments captures the current editor view. Preset views and camera render through a separate capture camera for two frames, then the user's editor camera is always restored; captures from parallel calls run one at a time. saveDir writes PNG files; uploadAs also uploads each image to the group as an Image or Decal asset (turn labels off for assets). Follow up with captureId + viewIndex + pixels to raycast what is under image pixels; captures expire after 5 minutes.
- `roblox_tree` — List the Roblox instance hierarchy. Paths look like "ReplicatedStorage/Shared" (or "Workspace.Map" when no name contains a dot), optional leading "game"; omit path for the whole game. Paths returned by other tools can be passed back unchanged.
- `roblox_find` — Find instances by name and/or className. Paths look like "ReplicatedStorage/Shared" (or "Workspace.Map" when no name contains a dot), optional leading "game"; omit path for the whole game. Paths returned by other tools can be passed back unchanged.
- `roblox_properties` — Read an instance’s common properties, attributes, and tags. Pass `properties` to read specific property names instead (unreadable ones are reported).
- `roblox_source` — Read a script’s source with line numbers. Long scripts come back in pieces; continue with startLine.
- `roblox_set_source` — Change a script's source through ScriptEditorService (works while the script is open in an editor; one undo step). Pass edits for targeted find/replace changes (each find must match exactly once), or source to replace the whole script.
- `roblox_execute` — Run Luau in the paired Studio place to create instances, change properties, or inspect values; print output and return values come back. Variables do not persist between calls. During a playtest it runs in the live game by default (context "server", or "client"), as a game script that shares the game's required modules and state; pass context "edit" for the place being edited. The 20s limit only interrupts code that yields (task.wait etc.): always put task.wait() in loops, since a non-yielding infinite loop freezes Studio.
- `roblox_places` — List connected Roblox Studio places and what each is busy with.
- `roblox_output_log` — Read captured Studio output, newest last, optionally filtered by level or text. Each result ends with a cursor; pass it back as since to get only newer entries.
- `roblox_selection` — Read or set the current Studio selection by instance paths.
- `roblox_playtest` — Start, stop, or check a Studio playtest. mode "run" (default) simulates without a character; "play" starts Play Solo. start waits until Studio has really entered the test (up to ~30s) and fails with the reason otherwise; stop waits until Studio is back in edit mode. While a test runs, execute, tree, find, properties, source, output_log and capture_view act on the live game (see their context argument); the other tools act on the edit place.
- `roblox_cloud_config` — Show the Open Cloud setup used by the upload, asset, game pass and developer product tools, or set the group id, the API key owner's user id (only needed for roblox_asset_quotas), and the default experience (universeId) for game passes and developer products. The API key itself is never passed through tools: the user puts it in the config file shown here or in DSH_ROBLOX_API_KEY. Environment variables override stored values.
- `roblox_create` — Create any Roblox item through Open Cloud. Files (max 20 MB, type picked from the extension unless type is given): FBX/GLB/glTF/RBXM → Model, inserted into Studio (make FBX with blender_export preset "roblox"); PNG/JPG/BMP/TGA → Image (or Decal); MP3/OGG/WAV/FLAC → Audio; MP4/MOV → Video; .rbxm KeyframeSequence → Animation (Blender animations: roblox_import_animation). Slow uploads return a job id for roblox_job_status. type GamePass or DeveloperProduct creates one on the experience (path is then an optional PNG/JPG icon); it stays off sale unless isForSale: true with a price. Roblox puts new passes/products on managed pricing (regional prices + price tests) by default: managedPricing: false keeps one fixed price, and gift: true (for gift passes) forces it off. Retries of the same create within 10 minutes return the first result unless force: true.
- `roblox_job_status` — Check a background job (uploads, captures uploaded with uploadAs, animation imports) by the job id those tools returned. Without jobId, lists recent jobs.
- `roblox_asset_status` — Check an Open Cloud operation id (from roblox_create or roblox_update) and report the asset id and moderation state once done.
- `roblox_get` — Read one item by id. type Asset (default, any asset kind): type, name, description, creator, state, revision, moderation, icon, previews. type GamePass / DeveloperProduct: name, description, sale state, price, managed pricing and which pricing features are active, icon.
- `roblox_list` — List items. type GamePass / DeveloperProduct: every one on the experience, with price, sale state and managed pricing, paged by pageToken. Asset types (Asset = all): Open Cloud cannot list a group's assets, so this lists assets uploaded through this toolpack (newest first).
- `roblox_update` — Update an item by id. type GamePass / DeveloperProduct: name, description, price, isForSale, managedPricing, gift (forces managed pricing off), path (new PNG/JPG icon); the result spells out every price, sale and pricing-mode change. type Asset (default): name, description, icon and previews (Image asset ids; square icon) for any asset; path uploads a new version of a Model (FBX/GLB/glTF/RBXM) keeping its id — slow updates continue as a roblox_job_status job, and Studio copies are not refreshed (re-insert with roblox_insert_asset).
- `roblox_asset_versions` — List an asset's versions (newest first) with their creator and moderation state, or read a single version by number. Use with roblox_rollback_asset.
- `roblox_rollback_asset` — Roll an asset back to an earlier version. Roblox publishes a new version with that version's content, so the asset id stays the same. List versions with roblox_asset_versions.
- `roblox_archive_asset` — Archive an asset (removes it from the website and stops it loading in experiences) or restore an archived one.
- `roblox_grant_asset_permission` — Let an experience use group assets it does not own, such as private audio, video, images, or models owned by a different creator than the experience. Needs an API key with the asset-permissions write scope. universeId is the experience (universe) id, not the place id.
- `roblox_asset_quotas` — Show the API key owner's asset upload quotas (for example audio uploads per month and video uploads per day): usage, capacity, and period. Uses userId, or the userId stored by roblox_cloud_config.
- `roblox_insert_asset` — Insert a Model asset (for example one uploaded by roblox_create) into the paired Studio place with InsertService:LoadAsset. The asset contents are moved under parent and selected.
- `roblox_import_animation` — Turn a dsh-animation JSON file (from blender_export_animation) into KeyframeSequences in Studio and upload each as a group Animation asset. Runs as a background job; returns the result, or a job id for roblox_job_status if it takes longer than ~40s. Retrying while it runs returns the same job.

## Install

In Unify, open the Hub, find this pack and choose Install. Unify downloads `pack.ts` from this folder, compiles it and writes it to your toolpacks folder. It also downloads `DSHBridge.server.lua` and runs `install.js`, which copies the plugin into Roblox Studio's Plugins folder. The **Finish setup** checklist (from `setup.json`) covers pairing Studio and the optional Open Cloud key.
