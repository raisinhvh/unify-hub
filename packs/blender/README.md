# Blender

Inspect and edit open Blender sessions: run Python (bpy), browse the scene, read/write properties, capture viewport images, render PNG icons and thumbnails, check meshes for game readiness, import, save and export models (including a Roblox FBX preset), convert armature actions or animation FBX files for roblox_import_animation, and look up the bpy API of the running version. Supports several Blender windows at once.

## Tools

- `blender_instances` — List connected Blender sessions (file, Blender version, scene, unsaved changes marked with *), what each is busy with, and results of commands that finished after their caller timed out. Use the instance id to target one when several are open.
- `blender_execute` — Run Python inside Blender on the main thread with bpy, bmesh, mathutils, Vector, Matrix, C (bpy.context) and D (bpy.data) preloaded. print() output and the value of a trailing expression are returned. Variables do not persist between calls. Operators (bpy.ops) run with the largest 3D Viewport as context. Changes are pushed as one undo step after the call. Selection, active object, mode and undo history are shared with the user and other agents: look objects up by name instead of relying on them, and never undo. In Edit Mode, obj.data is stale; use bmesh.from_edit_mesh(obj.data) or obj.update_from_editmode(). Blender is Z-up and uses meters. Python cannot be interrupted: keep each call well under the timeout.
- `blender_tree` — Show the scene outline: collections, objects (with parenting), their types, selection/visibility and modifiers. Pass root to start from a collection or object name.
- `blender_find` — Search objects (or any bpy.data collection via kind, e.g. "materials", "meshes", "images", "node_groups", "actions") by name, type, material, modifier, collection or selection.
- `blender_properties` — Read or set RNA properties. Without properties it lists every property. set takes {name: value}; vectors are arrays, enums are strings, ID pointers take a data-block name or null. Sets are one undo step. Functions cannot be called here; use blender_execute.
- `blender_selection` — Get the mode, active object and selected objects (plus edit-mode element counts), or set the object selection and active object. The selection is shared with the user and other agents; other tools take explicit target names instead.
- `blender_capture_view` — Draw the 3D Viewport to an image without moving the user's view, for checking work. Views: current (what the user sees), camera (scene camera), front, back, right, left, top, bottom, iso (orthographic, framed on target). With target and no views you get front/right/top/iso tiled 2x2 in one image; without target, preset views frame the selection. Shading: solid, wireframe, material, rendered (material/rendered may need a second capture while shaders compile, and rendered with Cycles can come out noisy). Overlays (grid, outlines) are off unless overlays is true. For final PNG images use blender_render.
- `blender_render` — Render a final PNG with Blender's renderer, e.g. Roblox icons, thumbnails and decals. Preset views place a temporary orthographic camera framed on target (the scene and the user's view are restored afterwards); view "camera" uses the scene camera. Other geometry is hidden from the render unless isolate is false. Engines: workbench (fast, studio lighting, default), eevee (scene lights and materials; first render compiles shaders) or cycles (slow; keep samples low). Returns the file path and a small preview. Without path, files go to the "exports" folder next to the .blend.
- `blender_output_log` — Read Python console output captured in Blender since the add-on started (prints and tracebacks from scripts, add-ons and handlers). Ends with now=<timestamp> to pass as sinceTimestamp later.
- `blender_mesh_check` — Game-readiness report for mesh objects: vertex/face/triangle counts, n-gons, open and non-manifold edges, inconsistent normals, loose and duplicate vertices, degenerate faces, UV maps, material slots and unapplied or negative transforms. Defaults to every visible mesh. profile "roblox" also flags more than 20,000 triangles, extra UV maps, vertices weighted to more than 4 bones and textures over 1024 px.
- `blender_api_lookup` — Look up the bpy API of the connected Blender version before writing code: a type ("Object", "bpy.types.BevelModifier"), a member ("Object.location", "Mesh.attributes"), an operator ("bpy.ops.mesh.primitive_cube_add", including whether it can run in the current context) or free text ("subdivision levels") to search type, operator and property names. Large types are listed by name only; look up a member for details.
- `blender_export` — Export objects to FBX, GLB/glTF, OBJ, STL, PLY or USD (selection and mode are restored). preset "roblox": FBX, Y-up/-Z-forward, unit scaling, embedded textures, no leaf bones; rigs get only the active action and deform bones. Warnings cover skipped objects (curves/text: convert first), skinned meshes without their armature and >20,000 triangles. Default folder: "exports" next to the .blend. Never overwrites unless overwrite is true. Lists each file with its size in meters and the settings used.
- `blender_import` — Import a model file (FBX, GLB/glTF, OBJ, STL, PLY, USD) into the open scene. Lists the new objects and actions so you can pass them as target to other tools. One undo step.
- `blender_save` — Save the open .blend file. With path, save as that file (the session then edits it) or, with copy, write a copy and keep editing the current file.
- `blender_export_animation` — Convert armature animations to a dsh-animation JSON file for roblox_import_animation (Open Cloud needs KeyframeSequences, not FBX). With fbx, the FBX is read by a separate headless Blender (open scene untouched; long runs continue as a blender_job_status job); otherwise the session's armature is used. Samples every frame (or every step frames) with constraints applied. Without actions, an FBX exports all takes and a session armature its current action. Output goes next to the FBX or to "exports" next to the .blend.
- `blender_job_status` — Wait for or check a background job started by blender_export_animation (fbx mode) or blender_install_addon. Without jobId, lists recent jobs.
- `blender_install_addon` — Install (or update) the DSH Bridge add-on into Blender's user add-ons folder and enable it, using a headless Blender run. Finds Blender automatically (Program Files, Steam libraries, DSH_BLENDER_PATH), preferring the version of a connected session, unless blenderPath is given. Open Blender windows need a restart afterwards.

## Install

In Unify, open the Hub, find this pack and choose Install. Unify downloads `pack.ts` from this folder, compiles it and writes it to your toolpacks folder. Then it runs `install.js`, which finds Blender and installs and enables the DSH Bridge add-on with a headless Blender run. If Blender is not found, the **Finish setup** checklist (from `setup.json`) shows how to install the add-on by hand.
